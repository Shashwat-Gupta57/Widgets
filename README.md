# Clock Widget

One of my [desktop widgets](https://dev.talken.in/projects/widgets.html) — this is the **`clock`** branch of [Widgets](https://github.com/Shashwat-Gupta57/Widgets). See the [main branch](https://github.com/Shashwat-Gupta57/Widgets) for all three.


## Run

These apps need **Java 21 or newer**. If you don't have it, install it once with the [JRE Installer](https://github.com/Shashwat-Gupta57/JRE-Installer/releases/latest) — one click, no admin rights. Every app looks for Java in the place it installs to first, then in `JAVA_HOME`.

Download `Widgets-clock-1.0.0-windows.zip` from the [latest release](https://github.com/Shashwat-Gupta57/Widgets/releases/latest), or from source:

```bash
javac *.java
java ClockWidget
```
